# 💰 MoneyFlow - Expense Tracker

A modern and responsive Expense Tracker built with **HTML, CSS, and JavaScript**.

MoneyFlow helps users manage their daily finances by tracking income and expenses, viewing balance updates, and analyzing spending with interactive charts.

---





# 🚀 Live Demo

(https://expense-tracker-nine-omega-54.vercel.app/)
---

# ✨ Features

- ✅ Add Income & Expenses
- ✅ Edit Transactions
- ✅ Delete Transactions
- ✅ Search Transactions
- ✅ Real-Time Balance Calculation
- ✅ Income & Expense Summary
- ✅ Interactive Doughnut Chart
- ✅ Dark Mode
- ✅ Local Storage Support
- ✅ Responsive Design
- ✅ Modern Dashboard UI
